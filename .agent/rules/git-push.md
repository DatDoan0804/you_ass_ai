# Git Synchronization Policy
- Whenever you finish modifying, creating, or deleting code files, you MUST immediately stage, commit, and push the changes to GitHub before concluding your response.
- Run `git status` first to verify modified files, write a concise conventional commit message (`feat:`, `fix:`, `refactor:`), and execute `git add -A && git commit -m "<message>" && git push`.
- Never leave uncommitted changes in the working tree after completing a task.
